# architecture-insuretech
Проект посвящён разработке технологической архитектуры для страховой компании InsureTech, которая столкнулась с проблемами производительности и отказоустойчивости при росте нагрузки.  Необходимо решить ряд задач: обеспечить бесперебойную работу сервиса 24/7, настроить динамическое масштабирование в Kubernetes, перейти на Event‑Driven‑архитектуру...
